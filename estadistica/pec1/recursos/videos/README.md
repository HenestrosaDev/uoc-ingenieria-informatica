## Introducción

Este directorio contiene una colección de lecciones en formato de vídeos educativos sobre estadística descriptiva y muestreo. Despliega cada sección para reproducir el vídeo correspondiente.

Cada vídeo tiene asociada una transcripción en formato PDF, ubicada en el directorio `transcripciones` de cada apartado.
