# PR2 - De la creación a la interconexión de microservicio

Para realizar esta PEC, hay que implementar en la [`plantilla`](plantilla/) brindada por el profesorado la funcionalidad que se pide en el archivo `enunciado.pdf`. * [Microservicio `Course`](https://github.com/UOC-SPRING-2026/spring-2026-course)
* [Microsericio `User`](https://github.com/UOC-SPRING-2026/spring-2026-user)
